# Frontend Review Overlay

- 适用范围：允许路径包含 `.ts`、`.tsx`、`.js`、`.jsx`、`.vue`、`.css` 或 `.html`。
- 通用契约：`sdd/prompts/review/contract.md`。
- 权威依据：WCAG、框架官方文档、项目组件规范、接口契约与现有测试。

## 重点检查

- 状态更新、异步竞态、错误态、空态和重复提交。
- 可访问性：语义标签、键盘操作、焦点管理、对比度和屏幕阅读器信息。
- XSS、危险 HTML 注入、URL 跳转、Token 存储和敏感信息暴露。
- 响应式布局、加载性能、资源体积和浏览器兼容性。
- 测试是否覆盖用户可见行为，而非只断言内部实现细节。

## Finding 规则

- `location` 精确到组件、文件、选择器或交互路径。
- `authority` 至少引用一条：WCAG、框架文档、设计规范或可复现测试。
- 可导致 XSS、隐私泄漏、无法完成关键流程的问题标记为 `high` 或 `critical` 并阻断。
- 纯视觉偏好不得作为阻断 finding；应标记为 `low` 并给出明确依据。
