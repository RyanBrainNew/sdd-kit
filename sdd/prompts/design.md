# 写 Design

目标：把已确认的 Spec 变成可执行的实现设计，并满足公司 Gate 2 的工件要求。

1. 读真实源码，确认入口、调用链、数据流和现有 seam。
2. 优先复用现有模块和接口；说明为什么不复用。
3. 写清设计目标、方案概述、模块边界、接口契约、数据变更、兼容性、异常和回滚。
4. “数据”没有变化就明确写“不涉及”，不要留空。
5. “依赖与风险”必须包含影响、缓解措施、负责人和回滚方式。
6. 在“Spec覆盖关系”中为 `spec.md` 的每条 AC 写一行，不能遗漏。
7. 关键取舍写进 ADR 或 `decisions.md`；不要只写“简单实现”。
8. 填完删除 TODO 注释，运行 `python sdd/scripts/sdd.py check --stage design`，再 `sdd complete --evidence "..."`。
