# FP-001 人工 G4 不得绕过 Review

## 症状

`l2-strict` 或其他人工 G4 流程在最后一个 Task 完成后，直接提示等待人工审批，
没有先校验独立 Review 证据。

## 根因

人工等待分支早于 G4 检查执行，导致缺少 Review、存在未关闭 finding 或证据不完整时
仍然进入人工确认。

## 触发条件

- G4 被配置为人工检查点。
- 最后一个 Task 已完成。
- `verification.md` 缺少独立审查，或 `review-findings.json` 仍有阻断 finding。

## 修复

先汇总并校验 Task 证据、Review 契约和 finding 状态。只有阻断项清零后，系统才提示
人工审批或自动迁移。

## 预防检查

- `CHK-001`：运行人工 G4 缺 Review 回归测试，命令必须失败并保持在 `IMPLEMENTING`。
- 回归命令：`python -m unittest tests.test_sdd.SddFlowTest.test_manual_g4_blocks_without_review -v`

## 适用范围

`sdd/scripts/sdd.py` 的 G4 完成路径。Pattern 只作为已验证参考，不能替代当前
Task 的真实测试证据。
